# Decisions

Record consequential choices and their reasons, not every implementation edit.
Current architecture belongs in [architecture.md](../architecture.md); dated
experiments and acceptance belong in the [evidence index](../evidence/README.md).

| Record | Status | Subject |
|---|---|---|
| [0001](0001-documentation-ownership.md) | Proposed; implemented as a reviewable pilot | Documentation ownership and navigation |
| [0002](0002-recovery-inputs-and-data-ownership.md) | Existing implemented design, recorded retrospectively | Recovery inputs and canonical data ownership |

New records use `NNNN-short-topic.md` with date, status, context, decision,
consequences, and links to evidence. Include alternatives only when actually
considered. Preserve superseded records and link their replacements; do not
rewrite an old decision to imply a different original rationale.
