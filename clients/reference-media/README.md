# Saved references on the Mac

This client archives Instagram Saved posts and Yaay saves while the Mac is
awake, then publishes private metadata into the existing local Obsidian vault.
Excalidraw is the primary board format; Canvas remains supported. Media Extended
renders the immutable server files inside note embeddables. Reference Boards
adds independent excerpt/frame commands, paused starts and playback coordination.

## Use

Open `References/Start here — reference board.excalidraw` in Obsidian. Open the
command palette and use **Reference Boards: Add a reference to this board**.
Search by title or collection, name the card, choose start/end and optionally
loop, then add it. **Choose excerpt or capture frame on this board** changes one
card or captures its current frame. Each addition creates an independent note;
copying the same note manually to another board deliberately shares that note.
Removing a card does not delete its note or canonical media. Native Excalidraw
notes, arrows and file embeddables support mind maps and itinerary cards.

`References/Archive` shows inventory/import status and links to collections.
`Sources` and `Collections` contain importer-owned blocks; annotations outside
those blocks survive refresh. `Projects`, drawings and `Frames` are user-owned
and never regenerated by catch-up. Collection names are display metadata, so
renames and reparenting do not move originals or break project references.

Videos are acquired eagerly by the collector, independently of opening boards.
The picker offers downloaded assets. Pending/unavailable sources remain visible
in collection notes. Full media stays outside the vault; only metadata, boards,
small JPEG thumbnails and selected still frames sync. Keep `References` outside
blog publication inputs: do not embed/link its private content from Blog articles.
The `private` field is descriptive; the existing blog exporter follows selected
article references, so it is not an access-control flag.

## Installation and authentication

Requirements: macOS, Chrome, Python 3, Homebrew FFmpeg, the existing local vault,
Media Extended and Excalidraw community plugins, and an enrolled
[restricted server endpoint](../../hosts/infra/reference-media/README.md).
Pinned acquisition dependencies are in `requirements.txt`.

The support directory is `~/Library/Application Support/dothomelab-references`
(mode 0700), outside Git and Syncthing. It holds the Chrome profile, scoped SSH
key, checkpoints, retry state and retained releases. Chrome uses its normal
macOS Keychain integration. Cookies are passed to gallery-dl only in memory;
no exported cookie file, storageState file, credentials in URLs or raw HTTP logs.

To enroll a new client, generate one dedicated Ed25519 key there, install only
its public key on the endpoint, and verify the PVE host key through the normal
SSH trust flow. Never give the collector a root key. Then create its virtualenv,
install the pinned requirements and sign in through:

```bash
"$HOME/Library/Application Support/dothomelab-references/venv/bin/python" \
  clients/reference-media/browser-session.py \
  --profile "$HOME/Library/Application Support/dothomelab-references/browser-profile"
```

Sign in to Instagram and Yaay, then close that separate browser. The helper
holds the collector lock during human sign-in; an active job must finish first.
Renew expired sessions the same way. Normal chat-browser sessions are unrelated.

From a committed checkout, install with actual deployment values:

```bash
python3 clients/reference-media/install.py \
  --vault /absolute/path/to/local-vault --host PVE_ADDRESS \
  --instagram-saved-url https://www.instagram.com/YOUR_ACCOUNT/saved/ --enable
python3 clients/reference-media/install-obsidian.py \
  --vault /absolute/path/to/local-vault --archive /Volumes/Media/references
```

Enable Reference Boards in Community plugins once; toggle it off/on after an
update. Install the [Media reconnect helper](../macos-media/README.md) for home
and the inspected private VPN route. The installer never changes vault sync or
installs an offline video cache.

## Catch-up and completeness

LaunchAgent `media.rafael.reference-collector` runs at login and every ten
minutes while awake. It does not wake the Mac. Each run takes a nonblocking lock,
checks the archive first, advances at most eight Instagram pages, and acquires
up to twelve pending posts. A completed Yaay scan is refreshed hourly; a completed
Instagram inventory is refreshed after six hours. Incomplete Instagram scans
resume their saved cursor. Source changes during root enumeration restart the
inventory without discarding its preceding submitted snapshots.

Yaay uses observed authenticated web synchronization from a fresh browser
context: explicit initial checkpoints, connected pagination, terminal pages,
root UI parity and both China boards' visible section headings. Native IDs,
weights, repeated memberships, empty lists, metadata and source URLs are retained.
The observed web schema exposes boards and sections; deeper recursive trees pass
fixtures, but native-app levels absent from the web sync cannot be inferred.

Instagram enumerates the visible Saved collection grid independently of media
downloads, including cards loaded while scrolling. gallery-dl supplies Saved and
collection pagination; explicit `more_available`/cursor validation is required.
Unfiled membership is computed only after every collection completes. Saved
soundtracks in Instagram's separate Audio picker are not Saved image/video posts.

A partial/failed scan never retires previous memberships. Complete scans mark
absent memberships inactive but keep history and media. Acquisition is marked
complete only after every returned image/video carousel member has a verified
upload/link receipt. Two failures pause acquisition for an hour; individual
retries back off to seven days. An unavailable original is retained as a source
record, not an empty import. No deletion operation exists on the archive endpoint.

Temporary download members are removed after completion acknowledgement; failed
work stays private for retry. Inspect retained files before manual cleanup; never
remove canonical objects to reset the queue. Logs contain counts/error classes,
not raw downloader exceptions. `worker-state.json` and `References/Archive` expose
last success, phase and delayed retries. A sleeping/offline Mac cannot report a
fresh heartbeat; timestamps are part of interpreting status.

## Verification and rollback

```bash
python3 -m unittest discover -s hosts/infra/reference-media -p 'test_*.py'
"$HOME/Library/Application Support/dothomelab-references/venv/bin/python" \
  -m unittest discover -s clients/reference-media -p 'test_*.py'
node --test clients/reference-media/obsidian/test-model.cjs
launchctl print "gui/$(id -u)/media.rafael.reference-collector"
```

`import-sample.py` repeats a bounded real sample, verifies carousel receipts and
generates thumbnails. It is an operator acceptance tool, not the ongoing scheduler.
`create-example.cjs` is a one-time installer that refuses existing files; source
refresh never invokes it. The dated [delivery evidence](../../docs/evidence/2026-11-02-reference-media-boards.md)
distinguishes actual playback/import checks from fixtures and pending remote work.

Pause future runs with `launchctl bootout
"gui/$(id -u)/media.rafael.reference-collector"`; use this when the worker is idle
unless intentionally interrupting a job. A stopped/incomplete upload is retried;
canonical objects are never overwritten. Retained release directories include
`DEPLOYED_COMMIT`. Restore the prior LaunchAgent plist from the support directory
and bootstrap it to roll back client code. Do not roll back the catalog database
or remove downloaded media. Plugin replacements are retained under
`rollback/<timestamp>/reference-boards`; restore that folder and toggle the plugin.
The read-only mount helper has its own timestamped binary/plist backups.
